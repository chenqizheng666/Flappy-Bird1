# Flappy Bird 重制版

纯原生 Canvas + JavaScript 重制，**零依赖、离线可玩**（不加载任何 CDN）。

## 项目结构

```
flappy-bird/
├── index.html          # 主入口（引用分离的 css / js）
├── standalone.html     # 旧版 p5.js 单文件备份
├── css/
│   └── style.css       # 页面样式
├── js/
│   └── game.js         # 全部游戏逻辑（原生 JS，IIFE 封装）
├── package.json        # 本地开发配置
└── README.md
```

## 运行方式

- **直接玩**：双击 `index.html` 即可（无需联网、无需服务器）
- **本地开发**：`npm run dev` 后访问 http://localhost:3000

## 操作

| 操作 | 按键 |
|------|------|
| 起飞 / 拍翅膀 | 点击 / 空格 / ↑ / 触屏 |
| 暂停 / 继续 | P（游戏中），切出窗口自动暂停 |
| 重新开始 | 结算后点击 / 空格 |

## 特性

- 🏗 **固定时间步长物理**（120Hz 模拟 + 渲染分离），不同刷新率下手感一致
- 🌗 **昼夜循环**：每 15 分平滑切换白天/黑夜（星空、月亮、萤火般的闪烁星星）
- 🏅 **奖牌结算**：10/20/30/40 分对应铜/银/金/铂牌 + 新纪录角标
- 💥 撞击白闪、死亡坠落到地面、粒子特效
- 🏞 视差远山、滚动地面草纹、体积光太阳/月亮
- 🔊 Web Audio 合成音效（拍翅/得分/撞击/坠落）
- 📏 圆形 vs 矩形精确碰撞，比包围盒判定更公平
- 📐 画布自适应窗口缩放，手机竖屏也可玩
- 🏆 最高分 localStorage 保存

## 参数调节

参数集中在 `js/game.js` 顶部的 `CFG` 对象：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `gravity` | 2100 | 重力加速度 (px/s²) |
| `jumpForce` | -560 | 跳跃力 (px/s) |
| `pipeSpeed` | 140 | 管道基础速度 (px/s) |
| `gap` / `gapMin` | 165 / 122 | 缺口初始/最小高度 |
| `spawnDist` | 220 | 管道间距 (px) |
| `speedGain` / `speedMax` | 1.6 / 90 | 每分提速 / 最大提速 |

## 旧版说明

`standalone.html` 是最初的 p5.js 优化版单文件备份，逻辑相同但依赖 CDN，仅供对比参考。
